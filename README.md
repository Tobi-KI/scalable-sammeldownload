# Scalable Sammeldownload (inoffiziell)

Chrome-Erweiterung: Markiere Transaktionen in Scalable Capital und lade alle
**Wertpapierabrechnungen** auf einmal als PDF herunter.

![Version](https://img.shields.io/badge/version-1.1.0-blue) ![Lizenz](https://img.shields.io/badge/Lizenz-MIT-green) ![inoffiziell](https://img.shields.io/badge/Status-inoffiziell-orange)

## Features

- Checkboxen an jeder Zeile der Transaktionsliste
- Sammel-Download aller markierten Wertpapierabrechnungen als PDF
- Dateinamen nach Schema `Wertpapiername_ISIN_Abrechnung[_Sparplan]_Datum.pdf`
- Läuft komplett lokal – keine Server, kein Tracking, keine Datenübertragung

## Installation

### Aus dem Chrome Web Store

*(Link folgt nach Veröffentlichung)*

### Manuell (Entwicklermodus)

1. Dieses Repository herunterladen (Code → Download ZIP) und entpacken
2. Chrome öffnen → `chrome://extensions`
3. Entwicklermodus (rechts oben) aktivieren
4. „Entpackte Erweiterung laden" → entpackten Ordner auswählen

## Nutzung

1. Auf scalable.capital einloggen → **Transaktionen**
2. Unten rechts Panel „📄 Sammeldownload"
3. Gewünschte Transaktionen anhaken
4. „Ausgewählte laden" → PDFs landen in `Downloads/scalable-dokumente/`
